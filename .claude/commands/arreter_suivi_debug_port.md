# /arreter_suivi_debug_port

1. Localiser l'automatisation de type heartbeat nommée `Traitement des commentaires Port` liée à la discussion courante.
2. La mettre en pause. Ne pas supprimer les commentaires, leurs captures, ni les fils F3.
3. Confirmer l'arrêt. Les commentaires non traités restent dans F3 avec leur statut actuel.
