# Assets de prévisualisation

Déposer ici une copie d’un asset à contrôler au format `.glb`, `.gltf` ou `.tscn`.
Le laboratoire détecte les fichiers au démarrage et les affiche sur le socle central.

Ces fichiers restent confinés au laboratoire. Ils ne sont ni importés dans `assets/`
ni référencés par le projet jouable.

## Contrôles

- `Page précédente` / `Page suivante` : changer d’asset.
- `R` : rotation de 45 degrés.
- `-` / `+` : modifier uniquement l’échelle de prévisualisation.
- `F2` : comparer les ambiances froide, neutre et alerte.

L’échelle `1,00` est la taille native. Le repère vertical près du socle est gradué
par mètre afin de détecter une mauvaise échelle ou un pivot incorrect.
