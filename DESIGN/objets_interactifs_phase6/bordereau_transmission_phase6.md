# Bordereau de transmission — phase 6

## Périmètre

16 exports GLB définis dans `inventaire_phase6_v1.md`, accompagnés de leurs fiches et du contrat d’état commun.

## Destination prévue

`assets/design/phase6/` dans une session d’intégration distincte. Aucun fichier de ce lot ne doit être copié directement dans le projet jouable par la zone DESIGN.

## Préconditions d’intégration

- Lire `fiches_integration_phase6_v1.md`.
- Conserver les collisions, navigation, transactions, machine de quête, timers et HUD existants.
- Utiliser `InteractionAnchor` pour l’invite ; relier les états de code aux variantes visuelles définies.
- Configurer les sons, animations de caisse et effets dans la session de code ou de VFX dédiée.

## Validation requise avant transmission

- Contrôle GLB automatisé réussi.
- Lot visible dans le laboratoire, sous les trois ambiances.
- Approbation utilisateur de la silhouette et des états.
