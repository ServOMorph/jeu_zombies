# Bordereau de transmission — phase 1

## Statut

Préparation uniquement. Transmission interdite avant production des modules, validation dans le laboratoire et approbation utilisateur.

| Champ | Valeur prévue |
|---|---|
| Lot | Kit modulaire structurel V1 |
| Inventaire | `inventaire_kit_v1.md`, IDs `NP-KMS-01` à `NP-KMS-23` |
| Format | `.glb` |
| Échelle | `1,00`, 1 unité Godot = 1 m |
| Pivots | définis dans `conventions_kit_v1.md` |
| Matériaux | 1 à 4 slots par asset, sans transparence |
| Chemin final prévu | `assets/environment/helix9/kit_structurel/` |
| Collision et navigation | non incluses ; blockout conservé |
| Portes | habillage visuel uniquement, compatible `HelixDoor` |
| Provenance et licence | création interne à confirmer asset par asset ; licence propriétaire cible |
| Validation laboratoire | chargement automatisé des 23 prototypes réussi le 2026-07-26 ; validation visuelle manuelle en attente, M3 non résolu |
| Approbation utilisateur | spécification et planche approuvées le 2026-07-26 ; validation des modules produites encore en attente |

## Pièces à joindre avant transmission

- exports `.glb` nommés conformément à l'inventaire ;
- fiches complétées, dont provenance et licence effectives ;
- résultats de contrôle laboratoire pour chaque module ;
- `rapport_validation_technique.md` complété par une validation visuelle lorsque M3 aura été retiré ;
- planche d'assemblage validée ;
- liste explicite des écarts ou placeholders éventuels.
